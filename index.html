01 / AI document workflowsBuilt & tested

Source documents.
A report ready for review.

A spreadsheet here. A management report there. Bringing them together meant repeating the same extraction, writing and formatting work.

I built workflows that extract the information, check figures across sources, draft commentary and produce a branded PDF.

A decision that mattered

Conflicting figures should trigger a check, not a confident paragraph.

Inside the build +

The workflow separates source extraction, commentary and rendering. Reconciliation checks surface discrepancies, and figures needing verification are flagged for review. The workflows are built and tested; ongoing adoption varies by project.

Document extraction / AI commentary / Validation / PDF output
02 / Reporting platformIn production

Usage data.
Reports delivered.

Account teams needed a consistent view of AI adoption across client accounts. Pulling the data and building each report by hand didn't scale.

I built a reporting console with PDF generation and scheduled delivery, then led its integration into a larger platform.

A decision that mattered

Generating a report and sending it are separate actions.

Inside the build +

Data collection, report generation and delivery run as separate stages. Reports go to the account team first. When the engine was migrated, output comparisons checked that the new version reproduced the existing reports.

Azure / API integrations / PDF rendering / Scheduled delivery
03 / Financial reconciliationProof of concept

Finding the errors
a spreadsheet missed.

The workbook wasn't just slow to produce. Comparing it with the source exports exposed incorrect values and missing records.

I rebuilt the reporting logic in Python and validated the results against source data. The tested outputs reconciled; broader client validation is the next step.

A decision that mattered

Code calculates the figures. AI doesn't invent the numbers.

Inside the build +

I traced how sales exports became a cash-versus-card workbook, reproduced the calculations in code, and compared the output with the manual version. Checking record coverage alongside totals helped reveal omissions that a headline total alone could hide.

Discovery / Python / Reconciliation / Workflow integration
